# 賽事 JSON（races.json）

前端是一個播放器：它照著 `races.json` 播放每一場比賽。所有玩家用同一份時程、同一個 seed，所以**同一時間看到的是同一場、同一個畫面**。檔案可以指定某幾場的名次、跑法、中途領先、終點差距和主播台詞；沒有指定的場次由產生器自動產生，對所有人也都一樣。

- **檔案位置**：`public/races.json`。
  - 本機網址：`http://localhost:5175/races.json`。
  - 正式網址：`https://fayipon.github.io/racehorse/races.json`。
- **換成 API**：建置時設定 `VITE_RACES_URL`，前端就改從該網址讀取同樣格式的 JSON。這就是之後線上機制要提供的介面。
- **讀取時機**：開頁時讀一次，之後每分鐘重新讀一次，切回分頁時也會重讀。
- **鎖定規則**：某場在這個分頁截止投注後就鎖定，之後的新檔不會再改變它。

## 時程

```json
{
  "version": 1,
  "cups": {
    "sunny":   { "epoch": "2026-09-01T00:00:00+08:00", "seed": 2718281828, "races": [] },
    "thunder": { "epoch": "2026-09-01T00:00:40+08:00", "seed": 1618033988, "races": [] },
    "royal":   { "epoch": "2026-09-01T00:01:20+08:00", "seed": 1414213562, "races": [] }
  }
}
```

- **每場 120 秒**：投注 60 秒（第 48 秒截止）、比賽 50 秒、賽果 10 秒。
- **`epoch`**：第 1 場開放投注的時間，必須帶時區，而且要在過去。
  - 第 N 場在 `epoch + (N − 1) × 120 秒` 開始。
  - 三個賽事錯開 40 秒，大廳隨時都有可以投注的賽事。
- **`seed`**：該賽事的共用亂數種子。
  - 改了 `epoch` 或 `seed`，所有玩家會一起換到新時程。
  - 換時程時，進行中的注單會退還。
- **場次編號**：
  - 內部場次是從 `epoch` 起算的絕對場次。
  - 畫面顯示的是每日場次 1–720，每天從 `epoch` 的時刻重新算。
- **`serverTime`**（選填，給未來的 API 用）：伺服器的毫秒時間戳記。前端開頁時用它校正時鐘（沒有時改用回應的 Date 標頭），之後整段瀏覽期間固定，比賽途中不會跳局。

## 指定一場比賽

```json
{
  "at": "2026-09-26T20:00:00+08:00",
  "order": [5, 3],
  "styles": { "5": "close", "3": "front" },
  "finish": "photo",
  "margins": [0.2, 1.5],
  "checkpoints": [
    { "at": 400, "leader": 3, "by": 2 },
    { "at": 900, "order": [3, 1] }
  ],
  "commentary": {
    "mode": "add",
    "lines": [
      { "at": -45, "clips": ["styleFront.3"] },
      { "at": -32, "clips": ["styleClose.5"] }
    ]
  }
}
```

| 欄位 | 說明 |
|---|---|
| `at` 或 `round` | 二選一。`at` 是該場開放投注的時間，必須帶時區，而且剛好落在某場的開始（陽光盃是偶數分的 00 秒，雷霆盃是偶數分的 40 秒，皇家盃是奇數分的 20 秒）。`round` 是絕對場次 |
| `order` | 名次，從冠軍開始，可以只寫前幾名。例如 `[5]` 只指定冠軍，其餘名次照常產生 |
| `styles` | 各馬跑法：`front` 領跑、`stalk` 跟前、`mid` 中段、`close` 後追 |
| `finish` | 第二名的差距等級：`photo` 鼻差（< 0.25 馬身）、`close` 接近（0.25–0.6）、`clear` 拉開（0.6–1.5）、`easy` 輕鬆（1.5–3） |
| `margins` | 精確差距，單位是馬身，每項是和前一名的差距，從第二名開始。每項 0.05–6，總和不超過 15。會覆蓋 `finish` |
| `checkpoints` | 領先的馬走到第 `at` 公尺時（以進度條的 1200 公尺計，範圍 150–1150，彼此相距至少 100）的名次。用 `leader` 指定領先者，或用 `order` 指定前幾名；`by` 是領先第二名幾個馬身（最多 4） |
| `commentary` | 主播台詞，見下節 |

**做不到的腳本**：播放器會先檢查整場跑起來是否自然，檢查項目是：
- 領先差距不會突然跳動；
- 追趕速度不超過真實比賽的最快速度；
- 沒有馬往後退。

做不到時，會依固定順序捨棄：最難的檢查點 → 差距 → 跑法，並在主控台顯示警告。所有玩家捨棄的結果都一樣。例如「第 1100 公尺 8 號領先 4 個馬身，但 5 號要贏」就來不及，那個檢查點會被捨棄。

**寫錯的欄位**：只會捨棄寫錯的那部分，並在主控台顯示 `races.json:` 開頭的警告。例外是 `order` 寫錯，這時整場都會被捨棄。

## 主播台詞

- `at` 是開閘起算的秒數，負數代表投注中（−60 是投注開始）。
- `clips` 是現有錄音片段的 ID，可以一次接好幾個。
- 四種語言的 ID 都相同，只是片段長度不同，所以台詞最多會順延 1.5 秒，排不進去就略過。

| `mode` | 行為 |
|---|---|
| `add`（預設） | 保留自動主播，腳本台詞先排，自動主播再補滿其餘空檔。台詞只能放在 **−55 到 −17 秒**（避開歡迎和截止提醒），或**開閘後 2 秒起、最後 230 公尺之前**。最後衝刺由自動主播一口氣報完，不能插話 |
| `replace` | 只播腳本台詞（−60 到 57 秒），連開閘和冠軍都要自己寫 |

自動主播本來就會照整場計畫描述比賽。所以指定了名次和檢查點之後，「拿到領先」「漂亮的逆轉」「鼻位之爭」這類台詞會自動跟著腳本走，通常只需要補投注期間的鋪陳。

### 片段 ID

- `N` 是馬號，1 到該賽事的馬數。陽光盃 8 匹，雷霆盃 10 匹，皇家盃 12 匹。
- 例子：`takesLead.3` 是「3 號拿到領先！」，`wins.5` 是「5 號拿下冠軍！」。

**投注期間**

| ID | 內容 |
|---|---|
| `welcome1.<cup>` | 歡迎來到該賽事（`<cup>` 必須是本賽事，也就是 `sunny` / `thunder` / `royal`） |
| `welcome2.<cup>` | 歡迎回到該賽事 |
| `welcome3` | 天氣晴朗 |
| `warmup` | 散步熱身 |
| `firstRace` | 今天第一場 |
| `equalOdds` | 機率都一樣 |
| `breeze` | 微風 |
| `fullStand` | 看台坐滿 |
| `betReminder` | 還沒下注的要把握時間 |
| `lastCall` | 投注馬上截止 |
| `closed` | 投注截止，往起跑線集合 |
| `gateQuiet` | 全場安靜，準備開閘 |

**比賽中**

| ID | 內容 |
|---|---|
| `gate` | 開閘了 |
| `breakAway.<馬數>` | 全部衝出來（`<馬數>` 必須是本賽事的馬數） |
| `evenBreak` | 起步很整齊 |
| `firstBend` / `backStraight` / `finalBend` / `homeStraight` | 第一彎道 / 對面直路 / 最後彎道 / 轉入直路 |
| `m1000` / `m800` / `m600` / `m400` / `m200` / `m100` / `m50` | 剩餘距離 |
| `tight` | 馬群緊湊 |
| `closeBehind` | 後面咬很緊 |
| `byOne` / `byTwo` | 領先一 / 二個馬身 |
| `oneLength` / `halfLength` | 只差一個 / 半個馬身 |
| `level` / `levelTwo` | 並排了 |

**終點**

| ID | 內容 |
|---|---|
| `line` | 過終點 |
| `photo` | 鼻位之爭 |
| `lastStride` | 最後一步逆轉 |
| `comeback` | 漂亮的逆轉 |
| `wire` | 一路領先 |
| `clear` | 輕鬆勝出 |
| `crowd` | 全場站起來了 |

**指名馬匹（`.N`）**

| 用途 | ID |
|---|---|
| 戰績 | `formTop3` `lastWinner` `twoWins` `runnerUp` `slump` |
| 跑法 | `styleFront` `styleStalk` `styleMid` `styleClose` |
| 場邊 | `grazing` `looking` `resting` `bio1` `bio2` |
| 比賽中 | `quick` `lead` `leads` `second` `third` `tracks` `rail` `wide` `midfield` `waiting` `last` `improving` `closing` `passes` `takesLead` `quickens` `holds` `fights` `outside` `inside` `nearer` `drives` `breaksOut` |
| 終點 | `call` `over` `wins` `secondPlace` `thirdPlace` |

各語言的完整台詞在 `scripts/commentary/<語言>.json`。

## 編輯守則

- 改完 push 到 main，CI 會先檢查這個檔案，再部署。檢查項目：
  - 沒有任何警告；
  - 每場腳本都完整做到；
  - 每句台詞在四種語言都排得進去。
- 部署加上快取約需 5 分鐘。**至少提前 20 分鐘 commit**，而且**不要修改已經開放投注的場次**。否則已經在看的玩家和剛進來的玩家，看到的那場會不一樣。
- 過期的場次可以定期刪掉，檔案保持精簡。
- 這個檔案是公開的，玩家可以事先看到腳本結果。現在用練習籌碼沒關係；之後的線上機制建議截止投注後才公開 `order` 和 `checkpoints`。
- 在本機測試時，把某場的 `at` 設成接下來幾分鐘內的開始時間，重新整理頁面即可。

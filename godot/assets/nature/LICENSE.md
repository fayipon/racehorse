# Stylized Nature MegaKit — Quaternius

- Creator: [Quaternius](https://quaternius.com/)
- Official pack: https://quaternius.com/packs/stylizednaturemegakit.html
- Free model bundle: https://poly.pizza/bundle/Stylized-Nature-MegaKit-T34GZFA0fm
- License: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-09-23

Fourteen free models were obtained individually from the author's public Poly Pizza
bundle. Model pages, original download URLs, triangle counts and original GLB
SHA-256 hashes are recorded in `manifest.json`.

`scripts/prepare_nature_assets.py` repackages the GLBs into glTF and geometry BIN
files. Embedded texture images are extracted and shared by content hash; geometry
and texture pixels are unchanged. The runtime glTF basename matches the original
GLB basename in the manifest. Original downloads are kept in the local ignored
`tmp/nature-source/` directory and can be retrieved from the manifest URLs.

The grass ground material, wind animation and planting layout are project code.
No paid Source-version shaders or engine project files are used.
